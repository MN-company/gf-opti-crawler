# Security policy

GF Opti Crawler is experimental research software and has not undergone an independent security audit. It must not be used with credentials or private user sessions, and it should run with the least privileges needed.

## Reporting a vulnerability

If GitHub's **Report a vulnerability** feature is available under the repository's Security tab, use it to send a private report. Otherwise, open an issue describing the affected component without including a working exploit, credentials, personal data or secrets. Maintainers can request further details through a private channel.

Do not publish vulnerabilities affecting the target website or attempt intrusive tests against it.
